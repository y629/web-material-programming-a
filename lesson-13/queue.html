演習13-6：キュー

最初に入れた値から取り出す。front と rear の移動を追って、先入れ先出しを確かめます。

ex13-6.c（ひな形）

可視化を操作する ↓

コードは容量100で、有効な操作を行う前提です。図では6要素に縮め、空・満杯の操作を止めます。

#include <stdio.h>

#define QUEUE_SIZE 100

int queue[QUEUE_SIZE];
int *front = queue;
int *rear = queue;

void enqueue(int x) {
    /* ここを埋める */
}

int dequeue(void) {
    /* ここを埋める */
}

int main(void){
    enqueue(1);
    dequeue();
    enqueue(2);
    enqueue(3);
    dequeue();
    enqueue(2);
    enqueue(1);

    dequeue();
    dequeue();
    dequeue();

    return 0;
}

−99〜99 の整数。空・満杯など、読み書きできない位置では操作を止めます。

0 / 10 操作

キューの配列

0 / 6 個
まだ操作していません← 古い値　新しい値 →

最初は空です。

見やすく6要素で表示（資料は100要素）。アドレスは説明用で、int を4バイトとして描いています。

ポインタが指す場所

front 次に読む場所

rear 次に書く場所

front は次に取り出す位置、rear は次に書き込む位置。2つが同じ位置なら空です。

直前に取り出した値

0 個取り出し
—

取り出した順

薄い値は現在のキューの外。取り出しても、配列に古い値が残ることがあります。右端の「末尾の1つ先」は、指すことはできても読み書きはできません。

このキューは資料と同じく末尾へ進む方式です。先頭側の空きは再利用せず、rear が末尾に達すると追加できません。
