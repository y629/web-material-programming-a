商と余りを、2つの変数に書き込む

商・余りの保存先を渡すと、void型の関数から2つの変数を更新できます。

ex13-3.c（ひな形）

可視化を操作する ↓
#include <stdio.h>

void divide(int x, int y, int *quotient, int *remainder) {
    /* ここを埋める */
}

int main(void) {
    int a = 100, b = 9;
    int quotient, remainder;

    divide(/* ここを埋める */);
    printf("quotient=%d, remainder=%d\n", quotient, remainder);
    return 0;
}

資料のひな形です。x・y は計算する値、quotient・remainder は結果を書き込む場所です。下の a・b を変えると、コードの初期値も変わります。

−999〜999の整数。割る数は0以外。編集すると最初に戻ります。
