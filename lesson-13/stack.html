演習13-5：スタック

最後に入れた値から取り出す。sp の移動を追って、後入れ先出しを確かめます。

ex13-5.c

可視化を操作する ↓

コードは容量100で、有効な操作を行う前提です。図では6要素に縮め、空・満杯の操作を止めます。

#include <stdio.h>

#define STACK_SIZE 100

int stack[STACK_SIZE];
int *sp = stack;

void push(int x){
    *sp = x;
    sp++;
    printf("IN : %d\n", x);
}

int pop(void){
    sp--;
    printf("OUT: %d\n", *sp);
    return *sp;
}

int main(void){
    push(1);
    pop();
    push(2);
    push(3);
    pop();
    push(2);
    push(1);

    pop();
    pop();
    pop();
    return 0;
}

−99〜99 の整数。空・満杯など、読み書きできない位置では操作を止めます。
