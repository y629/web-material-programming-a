swap：アドレスを渡して入れ替える

関数内のポインタから、main にある変数を書き換えます。

ex13-2.c

可視化を操作する ↓
#include <stdio.h>

void swap(int *a, int *b) {
    int tmp = 0;
    tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int a = 1, b = 2;
    swap(&a, &b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}

下の a・b を変えると、コードの初期値も変わります。*a と *b で、その先にある main の変数を操作します。
