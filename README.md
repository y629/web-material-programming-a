# プログラミングA

C言語の授業で使うインタラクティブな補助教材です。講義資料と併せて利用してください。

公開サイト: https://y629.github.io/web-material-programming-a/

- 第1回：Hello, world! の実行、gccのオプション
- 第2回：ファイルとディレクトリ、整数型とビット列、加減算
- 第3回：プログラムとフローチャート
- 第4回：条件分岐・繰り返し・配列（Web教材なし）
- 第5回：調整日（Web教材なし）
- 第6回：配列のループ処理、線形探索・二分探索、行列積
- 第7回：配列で2の累乗・階乗を計算
- 第8回：5つのソートの可視化と比較
- 第9回：関数の呼び出し・引数・戻り値と、演習9-1〜9-3
- 第10回：del_char、ランレングス符号化
- 第11回：調整日（Web教材なし）
- 第12回：テキストファイル入出力（Web教材なし）

各教材はステップ操作や値の編集に対応しています。連続再生・演出の切り替えができ、OSの動きを減らす設定も反映します。宿題の解答コードは画面に掲載していません。

ビルドは不要です。GitHub Pagesは main ブランチのルートを公開します。
