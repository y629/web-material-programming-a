線形探索

int found = -1;
for (int i = 0; i < N; i++) {
    if (a[i] == target) {
        found = i;
        break;
    }
}

二分探索

int l = 0, r = N - 1;
int found = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (a[mid] == target) {
        found = mid;
        break;
    } else if (a[mid] < target) {
        l = mid + 1;
    } else {
        r = mid - 1;
    }
}

l・r・mid は、その回に比較したときの位置です。次の探索で範囲を更新します。同じ値が複数あると、2つの探索で見つかる位置が異なる場合があります。
